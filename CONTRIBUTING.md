# Contribuir a la selección demográfica de CRABI

CRABI no tiene licencia aprobada. La presencia pública de estos archivos no concede una licencia de reutilización. La guía describe propuestas de cambios y no sustituye una decisión de derechos.

- Para errores, añade pasos reproducibles, entorno y resultados esperados/observados. Usa solo datos agregados o sintéticos.
- Para cambios metodológicos, especifica pregunta, población, denominador, unidades, supuestos, fórmula y límites.
- Para fuentes, registra URL, fecha, periodo, licencia, atribución y transformación. No incorpores tasas Red 2023 ni transcripciones o derivados ASPB sin permiso verificado.
- No incluyas identificadores, registros de pacientes, datos sanitarios individuales, secretos, tokens o archivos de acceso restringido.
- No describas escenarios como predicciones, recomendaciones clínicas, capacidad observada o efectos causales.
- Documenta comandos y versiones; no afirmes pruebas que no se ejecutaron.

La autora debe aprobar por separado la licencia del código y el uso de cualquier material de terceros.
